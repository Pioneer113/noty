Noty

Your notes live at the edge of the screen.

A native macOS sticky-notes app that sleeps as a thin stripe on the screen edge. Reach over and it fans into paper tabs. Click one and the note slides clear, full size, right where it sat.

Three states, one movement

It gets out of the way, then it doesn't.

The deck has exactly three states, and your pointer moves between them without a click. Nothing is ever docked, windowed, or in your way.

The deck

Five at a time, at full size.

Tabs lap over each other like roof tiles. That keeps the whole deck to about half the screen height while each tab stays tall enough to carry a readable label — the sixth note and beyond wait behind a +N tab that opens the full list.

  • →
    Sized to your titles. The uncovered strip of each tab measures itself against the longest title on the deck, so labels read in full instead of being clipped mid-word.
  • →
    Two deck styles. Labelled tabs, or bare colour chips that barely touch the screen. Right-click the pill to switch.
  • →
    One deck per display. Every screen gets its own dormant pill. The deck opens on whichever screen your pointer enters and the others stay shut.
  • →
    Over full-screen apps. Optional, off by default. Also picks its edge — right or left — and its text size.
  • →
    Archived, not deleted. Archiving pulls a note out of the deck but keeps it. Deleting gives you ten seconds to undo.
Checkbox tasks

Any line can be a task.

⌘T puts a checkbox on the current line. Click the box to tick it off and the line strikes through and dims. Return carries the list on to the next task; Return on an empty one ends it.

Tasks live inline in the note body as ☐ and ☑ prefixes, so a note is still plain text — nothing proprietary wrapped around it.

Markdown export writes them as standard - [ ] and - [x] task syntax, and import reads that straight back. All Notes shows a done/total count beside each note.

  • ☑
    Click the box. Not a modifier, not a menu. The checkbox is the hit target.
  • ☐
    Export intact. Markdown, plain text, one combined document, or a .stickies archive that round-trips colours, archived state and dates.
Local only

Your notes stay on your Mac.

There is no account, no sync, and no server holding your notes — because there is no network code in the app at all.

  • →
    Note bodies are encrypted. AES-GCM via CryptoKit, 256-bit. Titles, colours and timestamps stay readable so lists render without unsealing every row.
  • →
    A local SQLite database. In ~/Library/Application Support/Noty/. Yours to inspect, back up, or delete.
  • →
    No permissions asked. Global shortcuts go through the system hotkey API, which needs no Accessibility access. No Screen Recording either.
  • →
    No analytics, no SDKs. Nothing is measured and nothing phones home.

Check it yourself

# the body column is ciphertext
sqlite3 ~/Library/Application\ Support/Noty/notes.db \
  "SELECT hex(substr(body,1,24)) FROM notes;"

# and text from a note never appears in the file
strings ~/Library/Application\ Support/Noty/notes.db \
  | grep "a line from one of your notes"
Shortcuts

Reachable without the pointer.

The three global shortcuts work from any app. Standard editing — copy, paste, undo, select all — works everywhere too.

Anywhere
⌥⌘NNew note, opened straight away
⌥⌘AAll Notes — search across every note
⌥⌘LArchive
Inside a note
EscClose it, or dismiss the find bar
⌘FFind in note
⌘TTurn the line into a task, or strip the checkbox off
⌘.Cycle its colour
⌘⌫Delete, with ten seconds to undo
Build it

Xcode not required.

Noty is one swiftc invocation over a folder of Swift files, plus a script that assembles the app bundle and ad-hoc signs it. The Swift toolchain from Command Line Tools is enough.

./build.sh              # release → build/Noty.app
./build.sh debug        # fast, unoptimised
./build.sh release run  # build, then relaunch

open build/Noty.app
  • →
    macOS 15 or later. Swift 6 toolchain, SwiftUI and AppKit, no third-party packages.
  • →
    Around 2,700 lines. SQLite through its C API, CryptoKit for the note bodies, Carbon for the global hotkeys.
  • →
    Ad-hoc signed. Not notarised — moved to another Mac, Gatekeeper wants a right-click → Open the first time.
